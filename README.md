One line, from the retry loop that has retried the same request 4,096 times:

> I have retried this request 4,096 times and accept the server is not busy, it just does not like me; this letter is my last attempt.

`main.ts` (Node 22) writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR`).
